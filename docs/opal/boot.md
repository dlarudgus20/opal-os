# pc-x64 부트스트랩

GRUB은 Multiboot2 헤더를 읽고 32비트 보호 모드에서 `_start`로 진입합니다. `boot.asm`은 인터럽트를 비활성화하고 임시 페이지 테이블을 구성합니다. PAE와 EFER.LME 및 페이징을 켠 다음 GDT를 설치하고 far jump로 64비트 코드에 진입합니다.

64비트 진입 코드는 세그먼트 레지스터와 higher-half 스택을 설정한 뒤 C 함수 `kmain(void)`을 호출합니다. `kmain()`은 `test_run()`을 호출합니다. 일반 빌드에서 이 함수는 즉시 반환하며, 테스트 빌드에서는 COM1을 초기화해 테스트를 실행합니다. 반환 후에는 부트스트랩이 인터럽트를 끈 채 `hlt`를 반복합니다.
